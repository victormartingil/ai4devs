# Examples Directory

This directory contains two sets of AI agent configuration files:

## `templates/`

Generic, reusable templates with placeholders (e.g., `{{STACK}}`, `{{ARCHITECTURE}}`).
Use these as a starting point for any project regardless of language, framework, or architecture.
Copy the files into your project root and replace the placeholders with your actual values.

## `applied/`

A concrete, fully filled-in example using **Java 21 + Spring Boot 3 + Hexagonal Architecture**.
This shows exactly what the templates look like once all placeholders have been replaced
with real project-specific values. Use it as a reference when filling out the templates
for your own project.

## How to use

1. Browse `applied/` to understand what the final result looks like.
2. Copy the files from `templates/` into your project root.
3. Replace every `{{PLACEHOLDER}}` with your project-specific values.
4. Commit the files to your repository.
